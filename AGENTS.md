# Instrucciones para Codex

## Proyecto
Portfolio público de SER. (`https://byser.com.ar/`), marca de Sergio Gimenez, fotógrafo de moda y editorial en Buenos Aires, Argentina.

## Documentación
- Leer `docs/especificacion.md` antes de implementar funcionalidades.
- Consultar `docs/plan-implementacion.md` para conocer las tareas y su estado.
- Si hay contradicciones o decisiones pendientes, consultar antes de implementar.

## Tecnologías
- HTML5.
- CSS Vanilla.
- JavaScript Vanilla.
- JSON para la configuración de fotografías.
- VPS Debian con Nginx.

No utilizar React, Vue, Eleventy, Netlify ni frameworks innecesarios.

## Diseño
- Mobile first.
- Estética editorial minimalista.
- Todo el contenido visible en castellano.
- Fotografías sin títulos ni descripciones visibles.
- Respetar la identidad visual definida en la especificación.
- Escribir la marca visible como `SER.`; conservar `Sergio Gimenez` en «Sobre mí» como autor de las fotografías.

## Metodología de trabajo
- Trabajar en pasos pequeños.
- No implementar varias funcionalidades simultáneamente.
- Antes de modificar código, explicar brevemente qué se va a hacer.
- Después de cada cambio, ejecutar las pruebas correspondientes.
- Informar los archivos modificados y los resultados de las pruebas.
- No dar una tarea por terminada si las pruebas fallan.
- No modificar la arquitectura sin aprobación.

## Alcance
Desarrollar exclusivamente el portfolio público.

La aplicación privada de gestión de sesiones queda fuera de este proyecto.
